## 🚀 Guia Rápido: Railway (Mais Fácil)

### Tempo: 10-15 minutos

1. Acesse: https://railway.app
2. Crie conta (pode usar GitHub)
3. Clique em "New Project"
4. Escolha "Deploy from GitHub repo"
5. Selecione seu repositório
6. Railway detecta Node.js automaticamente
7. Configure variáveis de ambiente:
   ```
   PORT=3000
   JWT_SECRET=
   NODE_ENV=production
   ```
8. **PRONTO!** 🎉 Seu app está no ar!

**Custo:** $5 créditos grátis/mês (pode ser suficiente!)

---

## 🚀 Guia Rápido: Render (Grátis)

### Tempo: 15-20 minutos

1. Acesse: https://render.com
2. Crie conta (pode usar GitHub)
3. Clique em "New +" → "Web Service"
4. Conecte seu repositório GitHub
5. Configure:
   - **Name:** crm-gmp
   - **Environment:** Node
   - **Build Command:** `cd server && npm install`
   - **Start Command:** `cd server && node index.js`
6. Adicione variáveis de ambiente
7. Clique em "Create Web Service"
8. **PRONTO!** 🎉

**Custo:** GRÁTIS (com limitações) ou $7/mês
